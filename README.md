# StudyFlow — AI-Powered Study Platform

Organize your studies with AI: flashcards, quizzes, summaries, and lecture transcriptions all in one place.

## Features

- **AI Chat** — Ask questions and get instant answers about any subject
- **Flashcards** — Generate smart flashcards from your study materials
- **Quizzes** — Test your knowledge with AI-generated quizzes
- **Snapper** — Capture and OCR lecture notes and whiteboards
- **Recorder** — Record and transcribe lectures with AI
- **Study Dashboard** — Track your progress and study streaks

## Tech Stack

- **Frontend:** React 18, TypeScript, Vite
- **UI:** Tailwind CSS, Shadcn/ui, Framer Motion
- **State:** React Context API
- **Testing:** Vitest

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Run tests
npm test
```
